# GDP-extraction-and-processing
This project demonstrates web scraping and data processing skills by extracting real-world economic data from Wikipedia (IMF GDP Data) .


# Project Scenario

You are recruited as a Junior Data Engineer at an international firm expanding into global markets. Your task is to build a Python script that:

Scrapes the GDP data of countries from the IMF dataset.

Extracts and processes the top 10 largest economies in descending order of GDP (in Billion USD, rounded to 2 decimal places).

Uses Requests and BeautifulSoup for data extraction.

Cleans and organizes the data using Pandas and NumPy.

# Tech Stack

Python

Requests – Fetch webpage data

BeautifulSoup (bs4) – Parse HTML content

Pandas & NumPy – Data cleaning, processing, and analysis

# Key Learning Outcomes

Practical application of web scraping techniques.

Handling and cleaning raw HTML data.

Using Python libraries for data analysis and presentation.
